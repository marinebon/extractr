# extractr

The goal of the `extractr` R library is to provide easy to use
extraction and summarization functions in R for common datasets (ERDDAP,
Google Earth Engine, DataOne, etc).

For an example on how to use the functions, please see [Get
started](https://marinebon.github.io/extractr/articles/extractr.md).

## Roadmap

ERDDAP:

  Basic extraction from polygon for ERDDAP datasets:
[`get_ed_grds()`](https://marinebon.github.io/extractr/reference/get_ed_grds.md)

  Utility functions for ERDDAP metadata:
[`ed_dims()`](https://marinebon.github.io/extractr/reference/ed_dims.md),
[`ed_dim()`](https://marinebon.github.io/extractr/reference/ed_dim.md),

  Improve raster generation for non-rectilinear grids:
[\#3](https://github.com/marinebon/extractr/issues/3)

Google Earth Engine (GEE):

  Basic extraction from polygon for GEE datasets:
[\#4](https://github.com/marinebon/extractr/issues/3)
